# Core data stack
# Upper bound is deliberate, and not about the API.
#
# Windows Smart App Control blocks binaries it cannot attribute to a known
# publisher, and it judges by REPUTATION — so a freshly released wheel is
# blocked precisely because few machines have run it yet. pandas 3.0.5 was
# blocked on this machine ("Une stratégie de contrôle d'application a bloqué ce
# fichier"), taking geopandas, shap and statsmodels down with it, while 2.3.3
# loads fine. SAC has no allowlist, so pinning is the fix that does not require
# turning a security feature off.
#
# Revisit once pandas 3.x has been in the wild long enough to earn reputation,
# or on any machine where SAC is off. See docs/WINDOWS-SMART-APP-CONTROL.md.
